# ■ 운용 팁

- 프롬 순서: **품질 프리픽스 → 축 톤 꼬리표 → 베이스 → 표정 → 소품/배경 → 구도**
- **공격 모션은 태그로 직접 지시해야 한다.** 자세만 적으면 NAI가 정지 포즈로 그림. `holding <무기>` + 동작(`lunging thrust` / `overhead swing` / `punch` / `drawing bow`) + `foreshortening` + `motion blur` / `speed lines` 조합이 기본
- 필살기는 여기에 `extreme foreshortening` · `impact frame` · `dust cloud` · `light trail`을 얹어 한 프레임을 크게 키운다
- 플레이어 5인은 장면 축에 따라 베이스를 바꿀 것. 게임 베이스와 현실 베이스를 섞지 말 것
- 인물별 색 배정(일관성) — 줄리엣 `white silver, black` / 마커스 `dark green, light brown` / 정세라 `pink, brown leather` / 유하람 `blonde, green, brown` / 무명 `black, white mask` (현실=`black, pink`) / 베른하르트 `black iron, red` / 이스라 `olive green, amber` / 로한 `teal, gold, white fur` / 가르시 렌 `sandy blonde, rust brown` / 토르빈 `red, black apron` / 셀리아 `dark green, light brown` / 유안 `mint green, blue` / 네이아 `silver, dark green, purple` / 카시엘 `black, gold, red` / 마르타 `navy, grey`
- 드워프·할라크족·엘프는 종족 태그(`dwarf` / `black curved horns` / `elf, pointed ears`)를 가중치 1.2~1.3으로 올릴 것
- 첫등장(상황 1)은 `full body` + 43종 배경, 상황 2~11은 `upper body` + 인물샷 배경 프리셋
- 무명은 게임 이미지에서 **얼굴도 체형도 성별 단서도 드러나면 안 됨**. 가면·전신 외피가 곧 캐릭터이고, 현실 베이스는 ⓤ가 정체를 알게 된 뒤에만 쓴다. 이 인물만 표정 세트가 게임용·현실용 두 벌
- 무명의 게임 표정은 **얼굴이 아니라 움직임**이다 — 어깨·손·무게중심·망토·걸음으로만 감정을 잡고, `eyes` 계열 태그는 쓰지 않는다. 다른 14인과 반대로 `upper body`보다 `full body` 구도가 잘 맞는다
- 상황은 첫등장 + 표정 10종(평상시·기쁨·슬픔·당황·매우당황·부끄러움·분노·전투·필살기·절망) = 11종, 현실 세트는 필살기 제외 10종. 부상·사망은 이미지로 뽑지 않고 지문으로만 처리한다
- 매우당황은 당황의 증폭판 — 평소 감정 진폭이 작은 인물(줄리엣·무명·카시엘)일수록 여기서 처음으로 표정이 깨지는 것이 그림의 값이다
- 필살기는 실제 발동 턴에만 호출. 비전투 인물(로한·셀리아·마르타)의 필살기는 전투 기술이 아니라 그 사람다운 최후의 수단으로 잡았다
- 마커스는 서양인 외모가 흐려지기 쉬움. `caucasian` + `deep set eyes, high nose bridge, angular jaw` 네 개는 반드시 유지하고, **그의 이미지에만** 네거티브 `asian features, flat nose bridge`를 추가
