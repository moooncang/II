# 일레온 — 인수인계 (새 채팅용)

새 채팅의 Claude는 이 문서를 먼저 읽고, 아래 「파일」 목록의 최신본을 읽은 뒤 작업을 이어갈 것.
최신본은 클로드 아웃풋 폴더와 크랙 프로젝트 문서(`claude/일레온 …`) 양쪽에 같은 내용으로 있음. 기준일 2026-10-05.

## 0. 작가님과 일하는 방식 (가장 먼저 지킬 것)

- 호칭은 '작가님', 말투는 **존댓말**. 반말 금지
- 출력 위치(클로드 아웃풋)에는 최종 제작 파일만 둠. 작업용 파일·폴더는 Claude 작업 공간에서만 만들 것 (이전 세션에서 폴더 20개가 생겨 작가님이 불편해함)
- 파일을 고치면 **바로 그 파일을 다시 보내줄 것.** 수정 내용만 말로 설명하고 파일을 안 보내면 안 됨
- 글자 수는 **반드시 python `len()`으로 재서** 말할 것. 기준 = 띄어쓰기+줄바꿈 포함. 어림짐작 금지 (과거 4,393자를 5,900자로 잘못 말한 적 있음)
- 답은 짧고 실무적으로. 변경점만 간단히
- 작가님은 자주, 정확하게 정정함. 처음 해석을 고집하지 말고 바로 반영
- 크랙 프로젝트 지침: 설정 프롬프트 최대 7,000자 / 키워드 메모리 항목당 최대 400자

## 1. 프롬 작성 형식 (견본 = 「잔해의 테이머 메인 프롬 초안」)

- 구조: `# N.제목` 헤더 + `-` 불릿 + `[대괄호]` 그룹 + ` ·` 하위항목
- 압축 표기: 공백 최소화, 漢字·기호(✕금지/○허용/必필수/無없음/→순서)는 프롬 안 압축용으로만. 출력은 한글만
- **표(`|---|`) 금지, 불필요한 `**` 금지.** `**`는 대사 형식 `**이름**｜"대사"`에만
- `---`를 글 바로 뒤에 붙이지 말 것 (렌더링 깨짐)
- 정보창 예시는 **형식만** (`[Lv n] 클래스 · 단계`처럼). 실제 값 넣으면 AI가 그대로 베낌 → 작가님이 크게 화냈던 부분
- 프롬은 AI 내부 지시문. 진행 속도·등장 빈도·발동 조건을 프롬이 정하지 않음 (그건 유저 몫). "일이 생기면 어떻게 출력하는가"만 씀
- 메인 프롬에는 핵심만 압축하고 자세한 인물 정보는 키워드북으로. 단 메인에도 최중요 정보(Lv·직업·등급·성격·말투·외형 핵심·코드)는 압축 키워드로 반드시 남김. "비공개" 같은 빈칸 금지 — 프롬에는 정보가 다 있어야 함
- 인터넷 창은 코드블록 ```내용```만 고정, 안은 실제 인터넷 글처럼 자유
- 나레이션·지문은 문단마다 양끝에 `*` 필수 (`*문장*`)
- 시스템 메시지(월드메시지·레벨업·전직·알림 등)는 `내용`(백틱 인라인 코드), 풀다이브라 플레이어 간 기본은 음성 대화(일반 대사 형식), 채팅(귓속말·길드·파티챗)은 보조로 `>내용`. 둘 다 RP 중간에 삽입. 붉은 글씨·【!】는 쓰지 않기로 함(크랙에서 LaTeX 색상은 글자가 커지는 문제)
- 여론·인터넷은 RP를 멈추지 않고 **나레이션 중간에** 코드블록으로 삽입. 채팅·DM·알림은 자연스럽게, 커뮤·공략·위키·방송·기사 원문은 유저가 `!인터넷 - 궁금한 내용`을 입력했을 때만 (= ⓤ가 찾아보는 행동, 이미지·정보창 정상 출력). 메인 프롬 #9
- 요약 등 OOC 기능은 메인 프롬에 넣지 않고 크랙 **단축어**로 뺌. 단축어 제한: 작품당 20개, 이름 10자 / 설명 30자 / 본문 400자. 본문 형식은 `# 제목` + `-RP를 중단하고, 아래 코드블럭만 출력. RP 진행 금지` + 규칙 + 코드블록 양식
